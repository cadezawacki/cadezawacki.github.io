Lineup — code diff

Runs entirely in your browser. Nothing is uploaded anywhere.

Getting files in

  • Drag & drop files or whole folders onto either side, use the upload button, or just paste/type into the editor.
  • Multiple files are paired automatically by path → file name → name without extension. Change either side's file dropdown to pair files manually (⟲ in the Files panel resets).
  • Files that exist on only one side are flagged in the Files panel and in the banner.
  • The download button on each side saves the current file, or all / changed / unmatched files as a .zip (folder structure kept). Manage files lets you select files to zip or delete; deletes can be undone from the notification.

Comparing

  • Ignore options only change what counts as “equal” — your text is never modified. Ignored differences are still shown with a dotted underline.
  • Comments is language-aware (Python #/docstrings, JS/C# // /* */, VBA '/Rem, CSS, HTML, INI). Line order treats moved lines as equal (they're tinted lavender).
  • Transform tools (⋯ on each side, or “Both sides”) do change text: prettify/normalize, scrub comments or docstrings, tabs ⇄ spaces, trim, sort, adopt whitespace or casing from the other side. All undoable.
  • .bas .cls .frm are VBA. .cs is auto-detected as VBA or C# from its content — override with the language dropdown.
